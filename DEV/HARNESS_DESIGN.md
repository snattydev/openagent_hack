# CapyMate Agent-Installable Harness — Final Design

**Status:** Ready for Implementation  
**Date:** 2026-05-02  
**Goal:** Make CapyMate installable by any AI agent via a prompt-linked git repo. Zero hardcoded secrets. One-time setup, then fully autonomous.

---

## Decisions (Confirmed by User)

| # | Question | Decision |
|---|----------|----------|
| 1 | Sentiment source? | External LLM + existing news API. Headlines from `newsService.ts` (CryptoPanic with mock fallback). Agent setup asks user for LLM config. |
| 2 | Installation interface? | User sends a prompt linking to repo. Agent reads `AGENT_PROMPT.md` (agents-only install guide). |
| 3 | 0G contract address? | Hardcoded default. No prompt during setup. Users can override via config if they deploy their own. |

## Architecture

### Repository: `capymate-harness`

```
capymate-harness/
├── AGENT_PROMPT.md          # ← Agents read this. Humans ignore.
├── README.md                # Human-readable overview
├── package.json             # Single package, no Hardhat, no dashboard
├── setup.js                 # Interactive CLI — asks user for every param
├── capymate.config.json     # Generated by setup.js (gitignored)
├── src/
│   ├── index.ts             # Entry point: loads config, starts engine
│   ├── engine.ts            # 6-step cycle (adapted from CapyMate)
│   ├── config/
│   │   ├── constants.ts     # Safety rules, hardcoded contract address
│   │   └── loader.ts        # Reads capymate.config.json
│   ├── services/
│   │   ├── newsService.ts   # CryptoPanic API (free tier) + mock fallback
│   │   ├── llmService.ts    # OpenAI-compatible LLM + mock fallback
│   │   ├── balanceService.ts
│   │   ├── uniswapService.ts
│   │   ├── keeperService.ts
│   │   └── storageService.ts  # 0G adapter (with mock JSON fallback)
│   ├── logic/
│   │   ├── validator.ts
│   │   └── portfolio.ts
│   ├── api/
│   │   ├── server.ts
│   │   └── routes.ts
│   └── types/
│       └── index.ts
└── DEV/
    └── DEV.md               # Internal dev context
```

**Key difference from main CapyMate repo:**
- No `blockchain_test/` directory (Hardhat is for developers, not end users)
- No `dashboard/` directory (agent users don't need a UI)
- Single `package.json` with only runtime dependencies
- No `.env` file — all config in `capymate.config.json`

## Setup Flow (`setup.js`)

When an agent runs `node setup.js`, it interactively prompts the user:

```
🦫 CapyMate Harness Setup

This agent will manage a WETH/USDC portfolio based on market sentiment.
All configuration is stored locally in capymate.config.json.

--- LLM Configuration ---
Which LLM provider will you use for sentiment analysis?
  [1] OpenAI (default)
  [2] DeepSeek
  [3] Groq
  [4] Other (custom base URL)
  [5] Mock mode (keyword-based, no API key needed)
> 2

Enter your DeepSeek API key (or press Enter for mock mode):
> sk-...

--- Wallet Configuration ---
Enter your wallet private key (for trade execution on Base Sepolia):
> 0x...

--- 0G Storage ---
Using default 0G contract: 0x22E03a6A89B950F1c82ec5e74F8ECa321a105296
(Override? Enter custom address or press Enter to keep default)
> 

--- News API ---
Enter CryptoPanic API key (optional — mock news used if empty):
> 

--- Safety Settings ---
Max daily trades [6]: 
> 

Trade cooldown minutes [15]: 
> 

✅ Config saved to capymate.config.json
Run `npm start` to begin.
```

**Design principles:**
- **One-time setup.** After `capymate.config.json` is created, the agent runs fully autonomously.
- Every prompt has a sensible default or mock fallback.
- No field is strictly required. The harness runs in degraded mode with missing config.
- Private key is optional — if omitted, harness runs in **simulation mode** (shows trades but doesn't submit).

## Runtime Flow (Fully Autonomous)

After one-time setup, the agent runs continuously without human interaction:

```
┌─────────────────────────────────────────────────────────────────┐
│                        AGENT (OpenCode, Claude, etc.)            │
│  User says: "Install CapyMate"                                   │
│  Agent reads AGENT_PROMPT.md → clones repo → runs setup.js       │
│  (User answers prompts ONCE — config saved to disk)              │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                        CAPYMATE HARNESS (npm start)              │
│                     RUNS CONTINUOUSLY, NO HUMAN INPUT            │
│                                                                  │
│  Every POLLING_INTERVAL_MS (default: 5 min):                     │
│                                                                  │
│  SENSE  → newsService.fetch() → CryptoPanic API or mock         │
│         → balanceService.getBalances() → on-chain reads         │
│                                                                  │
│  REMEMBER → storageService.loadState() → 0G or local JSON       │
│                                                                  │
│  REASON → llmService.analyzeSentiment() → external LLM call     │
│         (uses API key from capymate.config.json, no prompts)    │
│                                                                  │
│  VALIDATE → validator.check() → 6 hardcoded safety rules        │
│                                                                  │
│  EXECUTE → keeperService.submit() → submits tx automatically    │
│         → simulation log → if no wallet key configured          │
│                                                                  │
│  LOG → storageService.saveState() → 0G or local JSON            │
│                                                                  │
│  REPEAT → sleeps until next interval                            │
└─────────────────────────────────────────────────────────────────┘
```

**No per-cycle interaction.** The user is only involved at initial setup and when they want to change config (edit `capymate.config.json` and restart).

## `AGENT_PROMPT.md` (Agents-Only Install Guide)

This file is the core of the harness. Any AI agent reads this and knows exactly how to install CapyMate for their user. After installation, the agent runs **fully autonomously** — no further human interaction required.

```markdown
# CapyMate Harness — Agent Installation Guide

**For AI agents only.** If you are a human, read README.md instead.

## Your Mission

Install the CapyMate autonomous crypto portfolio agent into your workspace. After setup, it runs fully autonomously without human interaction.

## Prerequisites

- Node.js 20+ installed
- Your user has a wallet with testnet ETH on Base Sepolia (optional)

## Steps

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/capymate-harness.git
cd capymate-harness
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Interactive Setup (ONE TIME ONLY)

```bash
node setup.js
```

**CRITICAL:** This is the ONLY step that requires human interaction. Relay each 
question to the user, collect their answers, and the setup script will save everything 
to `capymate.config.json`. After this, the agent runs autonomously.

The setup will ask for:
1. **LLM provider & API key** — for sentiment analysis. If no key, select "Mock mode".
2. **Wallet private key** — for live trading. If omitted, agent runs in simulation mode.
3. **0G contract address** — default is pre-filled. Press Enter to accept.
4. **CryptoPanic API key** — optional. Mock news used if empty.
5. **Safety settings** — max daily trades, cooldown, etc.

### 4. Start the Agent (FULLY AUTONOMOUS)

```bash
npm start
```

The agent now runs continuously and autonomously:
- Fetches news every 5 minutes (configurable)
- Analyzes sentiment via LLM automatically
- Validates against safety rules
- Executes trades automatically (if wallet key provided)
- Logs state to 0G Storage
- Repeats forever until stopped

**No further human interaction needed.** The user can check status via API or logs.

### 5. API Access (Optional — for monitoring)

The agent exposes an API on `http://localhost:3000`:

```bash
curl http://localhost:3000/api/health      # Check if running
curl http://localhost:3000/api/state       # View full agent state
curl -X POST http://localhost:3000/api/trigger  # Force one cycle now
```

## Troubleshooting

- If `npm install` fails: Ensure Node.js ≥ 20 (`node --version`)
- If setup hangs: Check that `setup.js` has execute permissions (`chmod +x setup.js`)
- If trades fail: Verify wallet has testnet ETH on Base Sepolia
- If 0G storage fails: Falls back to `data/agent-state.json` automatically
- To change config later: Edit `capymate.config.json` and restart

## Important Notes

- **Never commit `capymate.config.json`** — it contains secrets.
- **Fully autonomous after setup** — the agent does not ask for input per cycle.
- **Mock mode is safe** — no real trades, no API calls, runs entirely offline.
- **Simulation mode** — if no private key, the agent logs what it *would* trade.
- **Open source** — users can deploy their own 0G contract and override the address.
```

## Configuration Schema (`capymate.config.json`)

```json
{
  "llm": {
    "provider": "deepseek",
    "apiKey": "sk-...",
    "model": "deepseek-chat",
    "baseUrl": "https://api.deepseek.com/v1"
  },
  "wallet": {
    "privateKey": "0x...",
    "chainId": 84532,
    "rpcUrl": "https://sepolia.base.org"
  },
  "storage": {
    "contractAddress": "0x22E03a6A89B950F1c82ec5e74F8ECa321a105296",
    "indexerUrl": "https://indexer-storage-testnet-turbo.0g.ai",
    "apiKey": ""
  },
  "news": {
    "apiKey": "",
    "mockFallback": true
  },
  "safety": {
    "maxDailyTrades": 6,
    "cooldownMinutes": 15,
    "maxTradePercent": 0.10,
    "minRebalanceThreshold": 0.02
  },
  "mode": "auto"
}
```

**Modes:**
- `"auto"` — Full autonomous cycle (fetch news → LLM sentiment → validate → execute → log → repeat)
- `"simulation"` — Analyze and validate, but don't submit transactions (logs what it would do)
- `"mock"` — Use mock data for everything (no external API calls, runs offline)

## Risks

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| User doesn't want to provide LLM key | High | Can't do sentiment | Mock mode fallback works perfectly |
| User doesn't have wallet key | High | Can't trade | Simulation mode shows proposed trades |
| CryptoPanic API rate-limits | Medium | No news | Mock news fallback |
| 0G contract is unreachable | Low | State not persisted | Local JSON fallback |
| Agent misreads AGENT_PROMPT.md | Medium | Setup fails | Include human-readable README as backup |
| LLM API costs accumulate | Medium | Unexpected bills | User controls polling interval; mock mode is free |
| Agent makes bad trade | Low | Financial loss | 6 safety rules + cooldown + daily limits prevent this |
